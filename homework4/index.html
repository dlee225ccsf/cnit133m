Progressive Web Applications

PWA overview

A Progressive Web Application combines the reach of the web with app-like features. It uses responsive, device-independent HTML, CSS, and JavaScript so the interface works well on screens of many sizes.

PWAs can be installed through a supported browser and can use a web app manifest, icons, HTTPS, and a service worker. Service workers enable offline caching, faster repeat visits, and reliable loading even when a network connection is unavailable.
